# Heladería Dulce Frío

Este proyecto contiene una única página HTML autocontenida que muestra la identidad visual de la heladería **Dulce Frío**.  

- **Tipografía**: *Pacifico* (display) y *Montserrat* (texto).  
- **Diseño**: hero con ilustración de helado, sección de sabores en tarjetas, mapa incrustado y formulario de contacto.  
- **Responsive**: adapta su layout a móviles y tablets.  
- **Accesibilidad**: foco visible, respeta `prefers-reduced-motion`.  

Para usarlo, simplemente abre `index.html` en cualquier navegador. No se requieren dependencias ni compilación.
